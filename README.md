# Waves project workspace

Work is organized by Codex chat at the project root:

- `nh-surf-decline/` — **Analyze New Hampshire surf decline**: research code, downloaded data, reports, figures, and rendering scratch files.
- `public-spotter-buoy-map/` — **Map public spotter buoy data**: the public buoy-map artifact.
- `pacific-sea-level-anomaly/` — **Animate Pacific sea level anomaly**: Pacific animation, source subset, and the San Diego tide-gauge comparison.

Each folder contains its own README files and reproducible scripts. Generated products remain beside the source data and code that made them.
